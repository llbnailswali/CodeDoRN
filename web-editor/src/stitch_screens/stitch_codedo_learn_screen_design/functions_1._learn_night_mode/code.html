What is a function?

A function is a reusable block of code that performs a specific task.

EXAMPLE

A simple function

Kotlin
fun greet() {
println("Hello!")
}
info A function gives a block of code a name so it can be reused whenever we need it.

KEY IDEAS

1

Give code a name

Identify a reusable task.

2

Reuse the logic

Call the same code whenever you need it.

3

Accept input

Parameters allow a function to receive values.

4

Return a result

A function can send a value back to its caller.
