What is a loop?

A loop repeats a block of code so you don't have to write the same code again and again.

EXAMPLE

A simple loop

Kotlin
for (i in 1..3) {
println(i)
}
info A loop repeats the code inside its body for each value in the range.

KEY IDEAS

1

Repeat code

Run the same block multiple times.

2

Control repetition

Define how the loop progresses.

3

Work with sequences

Iterate through ranges or collections.

4

Stop at the right point

The loop ends when its repetition is complete.
