01

Simple function

Kotlin

Give a block of code a name.

fun greet() {
  println("Hello!")
}

WHAT IT MEANS

  • •fun → declares a function
  • •greet → function name
  • •() → no parameters
  • •{ } → function body
  • •println("Hello!") → code executed by the function

WHAT CHANGED

We gave a block of code a reusable name.

02

Calling a function

Kotlin

Run the code inside the function.

fun greet() {
  println("Hello!")
}

greet()

WHAT IT MEANS

  • •fun greet() → defines the function
  • •greet() → calls the function
  • •The call causes the code inside the function to execute.

WHAT CHANGED

We now use the function after defining it.

03

Function with a parameter

Kotlin

Allow the function to receive a value.

fun greet(name: String) {
  println("Hello, $name!")
}

greet("Alex")

WHAT IT MEANS

  • •name → parameter name
  • •String → parameter type
  • •name: String → declares a parameter that accepts text
  • •greet("Alex") → passes "Alex" into the function

WHAT CHANGED

The function can now receive input.

04

Multiple parameters

Kotlin

Allow the function to receive more than one value.

fun sum(param1: Int, param2: Int) {
  println(param1 + param2)
}

sum(4, 6)

WHAT IT MEANS

  • •param1: Int → first parameter and its type
  • •param2: Int → second parameter and its type
  • •sum(4, 6) → passes two Int values
  • •param1 + param2 → uses the received values

WHAT CHANGED

The function can now work with multiple inputs.

05

Returning a value

Kotlin

Send a calculated result back to the caller.

fun sum(param1: Int, param2: Int): Int {
  return param1 + param2
}

val result = sum(4, 6)

WHAT IT MEANS

  • •: Int → return type
  • •return → sends a value back
  • •param1 + param2 → calculated result
  • •result → stores the returned value

WHAT CHANGED

The function can now produce a value that other code can use.
