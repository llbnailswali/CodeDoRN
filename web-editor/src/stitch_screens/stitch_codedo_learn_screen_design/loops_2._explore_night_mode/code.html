01

Simple repetition

Kotlin

Repeat a block of code.

repeat(3) {

println("Hello!")

}

WHAT IT MEANS

  • •repeat → repeats a block of code
  • •3 → number of repetitions
  • •{ } → code block repeated
  • •println("Hello!") → code executed each time

WHAT CHANGED

We can now run the same code multiple times without copying it.

02

Basic for loop

Kotlin

Repeat code while moving through a range.

for (i in 1..3) {

println(i)

}

WHAT IT MEANS

  • •for → starts a loop
  • •i → loop variable
  • •in → takes values from a sequence
  • •1..3 → range from 1 through 3

WHAT CHANGED

The loop now gives us a different value on each iteration.

03

Changing the range

Kotlin

Control how many values the loop processes.

for (i in 1..5) {

println(i)

}

WHAT IT MEANS

  • •1..5 → range containing five values
  • •i → current value
  • •println(i) → prints the current value

WHAT CHANGED

Changing the range changes the number of loop iterations.

04

Loop through a collection

Kotlin

Process each item in a collection.

val names = listOf("Sam", "Alex", "John")

for (name in names) {

println(name)

}

WHAT IT MEANS

  • •names → collection
  • •name → current item
  • •in names → moves through the collection
  • •println(name) → processes each item

WHAT CHANGED

The loop can now process real data stored in a collection.

05

Loop with a condition

Kotlin

Repeat code while applying a condition.

for (i in 1..10) {

if (i % 2 == 0) {

println(i)

}

}

WHAT IT MEANS

  • •for → repetition
  • •i → current value
  • •if → condition
  • •i % 2 == 0 → checks whether the number is even
  • •println(i) → prints only matching values

WHAT CHANGED

The loop can now decide which values should be processed.
